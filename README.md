## 🌐 How to Deploy on GitHub Pages

1. Go to your repository on GitHub: `https://github.com/subhydv10/portfolio-web`
2. Click on the **Settings** tab (near the top right).
3. In the left-hand menu, click on **Pages** (under the "Code and automation" section).
4. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` and leave the folder as `/(root)`.
   - Click **Save**.
5. Wait 1–2 minutes, then refresh the page.
6. A green banner will show your live website link:
   > **`https://subhydv10.github.io/portfolio-web/`**
